# 53 低延迟版：分段时间与适用条件

本次在53中修改，51保留。扫描由每整轮1ms改为0.25ms，每行62.5μs；按下连续13次确认（首末观察相隔3ms），松开连续21次确认（首末相隔5ms）。逐键计数、完整帧发布和C4321映射保留。参数分别为KEYBOARD_ROW_CYCLES=3125、KEYBOARD_DEBOUNCE_FRAMES=13、KEYBOARD_RELEASE_FRAMES=21。

## 键盘识别

| 项目 | 修改前 | 修改后 | 依据 |
|---|---:|---:|---|
| 稳定触点到按下掩码，最坏扫描相位 | 5.7499ms | 3.4374ms | 50MHz真实参数RTL仿真 |
| 稳定断开到松开掩码，最坏扫描相位 | 5.7499ms | 5.4374ms | 同上 |

“13次”不是13ms，也不等于完整延迟3ms。还需要计入首次采样等待、行扫描与整帧发布。缩短的是稳定闭合识别；从手指开始按到触点稳定闭合的机械时间没有测量。若真实按键抖动超过3ms，需根据实板表现回调按下确认次数，现有仿真不能证明所有真实开关均无误触发。

## 本次完整数字链路仿真

测试使用A53实际顶层、默认扫描参数，以及本地B44实际顶层的仿真副本。没有改B板工程。两板均使用50MHz仿真时钟；传感器在A板被固定为中心八度、无颤音。测试的是钢琴C4、R1最不利采样相位的单键。B端先运行至稳定，再触发；仅为缩短启动等待，把仿真副本DAC启动静音计数设为16帧，正式B44仍为4096帧，稳态数据通路保持原逻辑。

| 段落 | 本次仿真时间 |
|---|---:|
| 稳定触点 → A键盘按下掩码 | 3.437401ms |
| 掩码 → 声部触发 | 0.000040ms |
| 声部触发 → 首个非零PCM | 0.009040ms |
| 非零PCM → B收到完整I2S左右样本 | 0.011720ms |
| B接收 → 后处理输出 | 0.000300ms |
| B后处理 → DAC输入端完整I2S样本对 | 0.020340ms |
| **稳定触点 → DAC数字输入端** | **3.478841ms** |

这是RTL仿真结果，不是实板录音。此处“输出”指首个非零数字样本，不能等同于音头已达到稳定音量。软件观察点有约1ns监测偏移。一个扫描/音频相位的实测仿真也不能当成所有相位、所有硬件的精确上界。

## 全链路保守预算

| 段落 | 预算 | 说明 |
|---|---:|---|
| 按下识别 | ≤3.4375ms | 稳定触点、最坏扫描相位 |
| A控制事件传递 | ≤0.0001ms | 数个50MHz时钟 |
| 等待音频帧、合成至A开始发送 | ≤0.0205ms | 合成在一帧内完成；避免把合成时间与等待下一发送帧重复累计 |
| A→B完整I2S样本对 | ≤0.0092ms | 6.25MHz位时钟，左右各24有效位 |
| B跨时钟FIFO和直通后处理 | 约≤0.001ms | 稳态、队列无异常积压；包含少量时钟相位余量 |
| B发送排队及DAC完整样本对 | 约≤0.032ms | 当前稳态桥接结构，留若干音频帧余量 |
| **到DAC数字输入端** | **约≤3.51ms** | 工程预算，不是实板保证 |

采样周期为512/50MHz=10.24μs。TI PCM5102A数据手册给出的正常插值滤波群延迟为20个采样周期，低延迟滤波为3.5个周期；在当前采样率换算分别约0.2048ms、0.03584ms。参见[TI数据手册滤波表](https://www.ti.com/lit/ds/symlink/pcm5102a.pdf)。实际模块的FLT引脚状态尚未核对，不能默认已经启用低延迟模式，也不能把群延迟当成精确的首个模拟电压出现时刻。

据此，稳态“稳定触点→DAC模拟响应”的工程估算为：**正常滤波约3.72ms，低延迟滤波约3.55ms**。用本次单一仿真相位相加则约3.684ms/3.515ms。最终需实测触点和DAC模拟端才能确认。

机械行程/触点抖动时间、外置功放/无线音箱缓冲、扬声器及空气传播时间不在上述数字内。从手指动作计时，应在上述估算基础上另加这些实际时间。保持原音色意味着乐器自身音头/包络上升过程也保留，听到明显音量的时间会随音色、音高、力度感受和判断阈值变化。

本地机械键盘发声不经过SPI轮询，不能给每次本地起音额外加固定1ms。B发起自动演奏等远程控制需另算SPI轮询/包传输；开机静音、失钟恢复也不属于稳态单次击键延迟。B44的4096帧启动门限约41.94ms，不是每次击键都增加41.94ms。

## 验证范围

真实参数按下/松开延迟、13/21非对称阈值、16键映射、独立消抖、128随机和弦、按下/松开抖动、复位按住恢复均有RTL检查。A实际I2S输出、TTP229/补光/B控制联动继续回归。两板完整数字链路测试文件为sim/tb53_end_latency.sv，日志为verification/tb53_end_latency.log。

3ms观察窗口比原4ms更短，因此实板仍需确认误触发、触点弹跳和快速连击。没有测量工具时，至少检查持续按住是否多次起音、松开是否误重触发以及快速交替按键是否漏音；这类试听不能代替模拟延迟测量。
