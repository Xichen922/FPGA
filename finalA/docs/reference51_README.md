## 实际硬件结构

实际输出统一来自instrument_core.u_shared32，旧piano_synth_core、musicbox_modal_core和十二套sine_voice不再列入活动综合清单。四音色使用同一套通路、相位/能量RAM及乘加器，不是四套完整核心套一个选择器。

共享核心有4条并行通路，每条分时处理3个固定声部；每声部有32个独立相位和分量能量状态，共12声复音。频率修正、能量衰减、分量幅度及输出包络分时复用乘法器；钢琴敲击噪声另有小乘法器，不计作振荡器。单簧管/风琴的频谱整形另设流水寄存器，避免组合运算直接接乘法器形成长路径。

钢琴与八音盒共用一张2048点单周期正弦表；钢琴原1024点数值与其偶数位置逐点一致，因此保留原相位量化。单簧管/风琴使用原256点、529285峰值波形的65点象限表，数值逐点校验一致。FPGA只保存合成参数和通用单周期波形，没有录音PCM/ADPCM播放通路。

切音色仍先淡出至零，再换音色、淡入；按你的确认，切换时仍按住的键会以新音色重新起音。四种音色不同时占用同一个声部保留旧音色尾音；同一音色内的逐键八度锁存、复音、重复击键和松键行为保留。

## 四种音色的32分量

| 音色 | 保留与新增内容 |
|---|---|
| 钢琴 | 保留原非零频率、幅度、相位种子和衰减，以及独立敲击噪声。原30槽中部分音区已有零幅度槽，本次补入弱独立共振，并增加两个弱失谐弦分量，总计32个非零初始激励、32种频率。新增/补入项快速衰减，避免长时间拍频抬音。 |
| 八音盒 | 保留原前6个非零主要分量；原第7槽实际为零，本次为第7槽及新增25槽配置弱金属共振。所有32槽均有非零初始激励，新增项主要修饰短音头，避免明显变厚、变刺。 |
| 单簧管 | 保留奇次泛音主结构、原弱偶次分量、音区均衡和气息噪声。每个分量新增独立能量状态，按住时保持，松键后按各分量速率缓慢下降，与原全局慢释放共同作用。 |
| 风琴 | 保留原主要泛音比例和32分量权重，每个分量独立保存相位与能量；按住持续，松键采用原全局慢释放并叠加轻微分量释放差异。 |

钢琴不新增长按维持或松键强制截尾；八音盒维持自然衰减。新增噪声未算作32振荡器的一部分。

32个独立计算分量不代表每个音区、每个时刻都能听到32个独立峰。钢琴高音区某些既有高次分量超过20kHz，弱分量会被掩蔽，分量也会衰减到量化零。本次会如实列出这些限制，不将其硬算作当时可闻分量数。

标量表：analysis/shared32_parameters.csv、shared32_piano_parameters.json、shared32_musicbox_ratios.json；单簧管/风琴逐分量权重及释放表为analysis/wind32_parameters.csv，对应shared32_core中的wind_shift和fetched_decay配置。活动参数ROM为src/shared32_parameters.v。

## 32分量说明

这里的32分量指正常演奏中的独立相位/能量状态。专用连续32频率测试程序和相关构建开关已移到工作备份，不随当前工程交付。

正常音色中的弱分量、已衰减分量或超出听觉带宽的分量，不当作当时必然可闻的峰。normal_piano_initial_bandwidth.csv仍用于披露各音区初始带宽上限。

audio/51_piano_five_notes_old_then_new_MODEL.wav和51_musicbox_five_notes_old_then_new_MODEL.wav均为离线定点模态模型，不是RTL/实板录音。顺序C3、C4、E4、G4、C5，每音先旧后新；同一音的新旧使用相同增益，保留真实幅度差异。每个音的单独文件也在audio中。你已选择按当前参考继续。
