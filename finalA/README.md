从实际 D 盘 example51 复制而来，51 源码和位流保留。只交付正常演奏版；没有独立频谱测试工程、测试位流或新模式 LED。B 板不修改。

## 实际发声路径与分量数量

实际输出为 `finalA_top.u_instrument.u_shared32`，模块实现是 `shared_modal_core`，正常编译参数 `PARTIALS=40`。实例名称保留是为了兼容回归检查，名称中的32不代表当前数量。

四种音色共用四条计算通道，每条顺序处理三个声部。每声部40个独立相位/能量上下文，12复音共480个；不是480套并排的物理乘法器。每个分量逐样本更新相位、能量、波形和累加。短噪声音头不计入振荡分量数量。

钢琴、八音盒原有32分量的频率、初相位、幅度及衰减参数逐项保留。钢琴新增8个较弱的失谐弦分量，八音盒新增8个较弱的金属共振分量。单簧管和风琴扩展到第40谐波，沿用原来的弱高次权重和各分量能量控制。C3～B5的40个分量频率均在奈奎斯特频率以下，但部分高次谐波会超过20kHz；衰减后也会变弱或归零，不能把“40个状态”说成“任意时刻人耳都能听见40个分量”。

RTL回归确认四音色、12声部的40个分量均有过非零贡献，且各上下文地址不重叠。没有补零分量凑数，也没有把噪声算作新增振荡器。

FPGA只使用参数和通用正弦表，没有PCM/ADPCM录音回放或预渲染音头。试听WAV和仿真参考向量不在综合清单内。编译、仿真通过不代表竞赛合规已获得组委会确认。

## 资源与结构优化

1. 用正弦的对称性将2048项全波表压缩成512项四分之一波表加端点，2048个输出值完全相同。
2. 初相位及噪声种子固定乘法改成常量查表，显式指定小表用逻辑实现。
3. 提前读取下一分量的状态和参数，删除每个分量单独的读取等待拍；使用40项紧凑地址步长，不按64项浪费空间。
4. 12个按键的响度、平滑状态仍独立；音频响度乘法合并为每条通道一个，保持相同截位和饱和规则。
5. 只有12条记录的包络存储拆成块存储器和窄寄存器组，避免小状态占满多个大存储块；不使用该器件不支持的分布式RAM。
6. 从生产源码移除9个不用的旧发声/频谱模块及参数表，删除失效的谐波参数传递和旧采样模型；回归参考仅放在 `sim` 中。单纯删掉本来就未综合的文件不计作硬件节省。

## 时序与帧预算

- 50MHz原约束下布局布线通过；Fmax 50.568 MHz，最差 setup余量 +0.225 ns，hold余量 +0.010 ns；综合0警告。
- 音频采样率为50MHz/512，即97656.25Hz。钢琴核心最后声部第373拍完成；四音色最晚PCM交付第497/512拍，余15拍。51最晚为509拍，余3拍。
- 选择40而非继续堆到41：当前调度每增加一个分量，风管音色要再增加12拍；41会重新逼近509拍，42会超出帧预算。本版保留当前余量。
- 本次低延迟更新：整轮扫描0.25ms，按下13次、松开21次确认。最坏扫描相位仿真按下3.4374ms、松开5.4374ms；完整A53+B44单键RTL到DAC数字输入为3.478841ms。模拟输出工程预算约3.55～3.72ms，取决于DAC滤波；不含未知机械抖动与外部音响延迟。详见[分段延迟说明](docs/latency.md)。

## 声音和行为保持

钢琴按下一次自然衰减，不恢复长按持续激励；八音盒自然衰减。单簧管、风琴按住持续，松开后从当前音量缓慢衰减到零。原逐键八度锁存、12复音、重复击键、松键尾音和切音色淡出/再起音策略保留。

C4321机械键盘、13～16音色直选、TTP229分区与冲突处理、摇杆、编码器、单通道光敏DO补光、SPI/I2S、B44跟弹及自动播放均保留。没有新增或改动接线。
